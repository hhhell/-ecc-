# Lightweight ECC Algorithm Research & Implementation

##  项目简介
本项目旨在研究适用于资源受限环境（如 IoT 设备）的轻量级椭圆曲线密码学（ECC）。项目涵盖理论参数选型、底层算法优化及 ECDH 密钥交换协议的完整工程实现。

##  核心技术
- **底层优化**：基于梅森素数（Mersenne primes）优化有限域模运算，利用位运算提升计算效率。
- **抗侧信道攻击**：引入 **Montgomery Ladder（蒙哥马利阶梯）算法** 实现标量乘，通过固定计算流程消除分支操作，有效抵抗时间/功耗等侧信道攻击。
- **协议实现**：完整实现 **ECDH（椭圆曲线密钥交换）** 协议。

## 研究与实现过程
1. **参数选型**：对比不同曲线模型（Weierstrass、Montgomery 等），分析其在性能与安全性上的差异，完成参数选择。
2. **算法实现**：编写代码实现有限域上的点加与倍点运算，并实现 Montgomery Ladder 标量乘算法。
3. **协议测试**：模拟双方公私钥生成过程，实现 ECDH 共享密钥计算，并搭建实验环境验证通信的正确性与效率。

##  实验成果
- 成功验证了轻量级 ECC 算法在资源受限环境下的安全性与可行性。
- 输出完整的密码学工程实践报告，深入理解了底层加密通信机制。
